# Dashboard_Vendas_Porsche
Projeto DIO - Dashboard de vendas da Porsche
  Quais perguntas de negócio você escolheu, e por quê?
1 - Qual é o total de vendas?
2 - Qual modelo mais vendido?
3 - Qual cidade mais vende? E quais modelos são vendidos nessa cidade?
Escolhi essas perguntas, para auxiliar os executivos em tomada de decisão.
Executivos precisam acompanhar o faturamento, qual é o produto mais vendido, locais onde mais vende e quais produtos esses locais compram.

  O prompt que gerou a dashboard, e o que mudou nele até a versão final?
Prompt inicial:
  Utilizando o recurso de canvas, renderize uma dashboard em html ao lado.
#Filtros
-> Modelo da Porsche
-> Model Year 
-> City
-> Pay method
#perguntas de negócios e kpis
-> Quais os principais modelos de carro vendido por cidade?
-> Qual o ano de modelo de carro mais saiu em um período?
-> Quero insight de carros populares de vendas com base nos dados em cada cidade
Sobre o ui/ux, se baseie no site oficial da porsche brasil: 
https://www.porsche.com/brazil/pt/
tenha um ar de elegante e refinado.
